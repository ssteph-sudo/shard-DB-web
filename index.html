SHARD-DB

Scalable Hash-Based Retrieval for High-Throughput Reference Database Construction

About SHARD-DB

SHARD-DB explores a different strategy for marker-specific reference-database construction: broad MinHash/LSH candidate retrieval followed by targeted locus localization rather than alignment-first expansion.

The project investigates scalable sequence retrieval across large nucleotide collections, with particular emphasis on memory efficiency, data movement, candidate localization, and workload-dependent performance across marker families.

Research status: SHARD-DB is active, unpublished research. Source code is not currently publicly available.
